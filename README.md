An intelligent AI-powered interview platform that simulates real technical interviews with voice interaction, resume parsing, live coding evaluation, and instant feedback powered by Google Gemini.

---

## 🚀 Features

* 🎤 **Voice-Based Interaction**: Real-time conversational interview with speech-to-text (AssemblyAI) and natural voice synthesis (Murf AI).
* 📄 **Resume Parsing**: Automatic PDF resume analysis to generate tailored interview questions matching the candidate's actual background.
* 💻 **Live Code Editor**: Built-in Monaco code editor supporting JavaScript, Python, Java, C++, and more.
* 🤖 **AI Feedback & Scoring**: Instant scoring and actionable feedback on answers generated by Google Gemini 2.5 Flash.
* 📊 **Interview History**: Track past interview sessions, questions, performance ratings, and progress over time.
* 🔐 **Authentication**: Secure JWT authentication with MongoDB database persistence.

---

## 🛠️ Tech Stack

### Frontend
* **React 19** with **Vite 6**
* **React Router v7**
* **Monaco Editor** (`@monaco-editor/react`)
* **Axios** & **React Hot Toast**

### Backend
* **Node.js** & **Express 5**
* **MongoDB Atlas** with **Mongoose 9**
* **Vercel Serverless Functions** (`/api/*`)
* **JWT & bcryptjs** for secure auth

### AI & Cloud APIs
* **Google Gemini API** (`@google/genai`)
* **AssemblyAI** (speech-to-text)
* **Murf AI** (text-to-speech audio streaming)
* **unpdf** (serverless-native PDF text extraction)

## ⚙️ Local Development Setup

### 1. Clone the repository
```bash
git clone https://github.com/MohithKumarVemuri/Personalized-AI-Interview.git
cd Personalized-AI-Interview
```

### 2. Backend Setup
```bash
cd server
npm install
npm run dev
```

### 3. Frontend Setup
```bash
cd client
npm install
npm run dev
```
